# vibe-coding-projects

A curated collection of creative coding projects that bring good vibes through technology.

## Projects List

### 1. Mood-Based Music Player
A music player that adapts to your current mood using sentiment analysis and creates personalized playlists.
- **Tech Stack**: Python, Spotify API, Machine Learning
- **Vibe**: Emotional resonance through music

### 2. Ambient Soundscape Generator
Generate calming ambient soundscapes based on nature sounds, white noise, and binaural beats.
- **Tech Stack**: JavaScript, Web Audio API, React
- **Vibe**: Relaxation and focus

### 3. Positive Affirmation Bot
A chatbot that sends daily positive affirmations and motivational messages.
- **Tech Stack**: Node.js, Discord/Telegram API
- **Vibe**: Daily positivity boost

### 4. Sunset/Sunrise Notification App
Get beautiful notifications for sunrise and sunset times with inspiring quotes.
- **Tech Stack**: Python, Weather API, Push Notifications
- **Vibe**: Connection with nature's rhythms

### 5. Collaborative Gratitude Journal
A web app where users can share and read gratitude entries from around the world.
- **Tech Stack**: React, Firebase, Tailwind CSS
- **Vibe**: Global positivity and thankfulness

### 6. Breathing Exercise Timer
Visual and audio-guided breathing exercises with customizable patterns.
- **Tech Stack**: HTML/CSS/JavaScript, Canvas API
- **Vibe**: Mindfulness and stress relief

### 7. Color Therapy Visualizer
Interactive visualizations that use color psychology to influence mood and energy.
- **Tech Stack**: Three.js, WebGL, React
- **Vibe**: Visual healing and creativity

### 8. Plant Care Reminder System
Track and get reminders for watering and caring for your plants.
- **Tech Stack**: Flutter, SQLite, Local Notifications
- **Vibe**: Nurturing life and greenery

### 9. Retro Vibe Terminal
A terminal emulator with retro aesthetics and soothing color schemes.
- **Tech Stack**: Electron, Node.js, CSS
- **Vibe**: Nostalgic computing experience

### 10. Constellation Story Generator
Generate stories and meanings for star constellations with AI.
- **Tech Stack**: Python, OpenAI API, Astronomy Data
- **Vibe**: Cosmic wonder and imagination
