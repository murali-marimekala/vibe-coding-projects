# Web Applications

This directory contains full-stack web applications, single-page applications (SPAs), and progressive web apps developed with GitHub Copilot assistance.

## Projects

### [Simple Todo App](todo-app/)
A minimal todo list application built with vanilla JavaScript and GitHub Copilot assistance.
- **Features**: Add, complete, delete tasks; filter views; localStorage persistence
- **Technologies**: HTML5, CSS3, Vanilla JavaScript
- **Learning Focus**: DOM manipulation, event handling, state management

*More projects will be added here as they are developed*

## Common Technologies

Projects in this category may use:
- **Frontend**: React, Vue, Angular, Svelte, vanilla JavaScript
- **Backend**: Node.js, Python (Flask/Django), Ruby on Rails
- **Styling**: CSS, Sass, Tailwind CSS, Bootstrap
- **State Management**: Redux, Vuex, Context API
- **Build Tools**: Webpack, Vite, Parcel

## Getting Started

Each project has its own README with specific setup instructions. Generally:

1. Navigate to the project directory
2. Install dependencies (e.g., `npm install` or `pip install -r requirements.txt`)
3. Follow the project-specific setup instructions
4. Run the development server
